# Implementation and measured results

Measured on Linux on 2026-10-26. Workflows remain experimental and opt-in
(`CU_WORKFLOWS=1`). The full rollout gate has **not passed**.

## Changes delivered

- Parameterized, revisioned browser/native workflows with scope checks, UI
  validation, bounded execution, output extraction and automatic validated reuse.
- Durable write receipts, scope locks, uncertain-outcome reconciliation and
  explicit stale-lock recovery. Possible writes are recorded before dispatch.
- Batched browser observations, scoped snapshots and lazy element handles.
  Optional same-origin GET acceleration requires matching UI validation.
- Linux AT-SPI observations/actions with guarded visual fallback; GTK popup with
  drag/cancel and acknowledged exclusion from captures. Existing Mac popup kept.
- Local Codex app-server transport for Pomerado OSS, without new API credentials.
- Benchmark runner, independent grading, frozen baseline preparation, synthetic
  browser fixtures, native GTK fixture and raw/HTML reports.

Usage and constraints: [workflows](WORKFLOWS.md), [benchmark protocol](BENCHMARKS.md).
No upstream code was copied into the runtime.

## Browser observation microbenchmark

Frozen CU `d6e271bfbf4a1899b809c27c5530896ef1296aa7` versus this working tree;
Chromium 1234, Node 24.18.1, Ryzen 9 7900X, 20 alternating pairs per fixture.
All 120 observations passed. Mean milliseconds:

| Buttons | Frozen CU | Candidate |
| --- | ---: | ---: |
| 100 | 95.94 | 17.08 |
| 400 | 356.54 | 57.77 |
| 1,000 | 540.11 | 51.44 |

Geometric mean of task speedups: **7.14×**. This measures warm observations only,
excluding model, popup and complete-task time. Measurements ran alongside final
validation work, so absolute timing is subject to host contention.

## Pomerado read replay microbenchmark

Pomerado OSS 0.4.0 commit `1d8a016862b6b1c8e43c770a75514d487efb8bc5`,
Node **24.21.0** (supported), same Chromium executable, 20 alternating pairs.
The Pomerado artifact was generated by its minter through the Codex provider
adapter; CU's declarative workflow was manually authored. Both reload a local
page and return the same independently checked nonempty heading.

| Runtime | Mean ms | Verified runs |
| --- | ---: | ---: |
| Pomerado artifact | 531.80 | 20/20 |
| CU workflow | 35.01 | 20/20 |

Paired estimated speedup **15.19×**, bootstrap 95% interval **14.54–16.02×**.
This is one tiny read operation with warm library sessions. It excludes outer-agent
turns, minting, repair, popup and native work. It does **not** establish that CU is
15× faster on real tasks, nor compare stock Pomerado Cloud.

Read minting and saved-artifact replay passed. Disposable write minting did not
publish: Pomerado Guardian rejected commit-boundary ordering before the deadline.
Both mint probes used Node 24.18, below upstream's supported version; repeat them
on supported Node before a compatibility release. The separately measured replay
above used supported Node. Full provider compatibility remains unproven.

Authenticated Codex, UI-only browser search, one seed and one run per competitor,

| --- | ---: | --- |
| Frozen CU | 36.38 s | Passed |

## Validation and remaining gates

- Typecheck, build and whitespace checks: passed.
- Test suite: **201 passed, 1 skipped, 0 failed**. Skip: Mac native broker test;
  no Mac hardware available.
- Live Linux GTK test under Xvfb/D-Bus: passed AT-SPI save, independent persisted
  file verification, screenshot-backed raw fallback, popup/cancel and capture
  exclusion.
- npm tarball: CLI workflow schema, required packaged files, native helper install
  and bundled Linux driver status passed. Dependencies were shared from the locked
  workspace install; this was not a clean registry installation or live packaged
  desktop run.
- Not run: Mac live workflows, complete 24-task suite, real editor/file-manager/
  spreadsheet cross-app comparisons, cold/changed/interrupted repair benchmarks,
  full end-to-end repeat-workflow benchmark, and hosted Pomerado comparisons.
- Native shared-broker semantic execution remains unsupported. The existing broker
  protections still refuse unleased legacy input.
- Workflow spans cover observation/dispatch/HTTP; complete queue/startup/model
  latency accounting and reliable provider token/cost accounting are not finished.

The catalog contains 12 browser, 8 native and 4 cross-app task templates. Native
and cross-app templates need application-specific reset/evaluator adapters; their
presence is not a measured benchmark result. Mode labels do not simulate cold
startup or repair automatically. Keep the 2× aggregate repeat-task target pending
until representative paired measurements and write-fault checks pass.
